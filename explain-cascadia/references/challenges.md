# Challenges and Scenarios (Herausforderungen)

**GS** = base game rulebook (DE), **LM** = Landmarks rulebook (DE). Printed page = PDF page. Species order in card lists: **bear / elk / salmon / hawk / fox**.

---

## Base game challenge mode
**Rulebook:** GS S. 12

- Read only once you know the normal game well. **50 challenges** across three areas; before each game decide freely whether to use this mode and pick one area: **Scenarios (15)**, **Normal game (25)**, **Rule variant (10)**.
- Progress track ("hiking route", image GS S. 12): write your name in an empty field; each of up to **5 players** has a route with its own symbol (brown circle, beige oval, pink triangle, blue diamond, orange square) that appears on each challenge. Milestones on the route: **8** "Durch Flüsse", **16** "Durch Feuchtgebiete", **24** "Durch Wälder", **32** "Übers Gebirge", **40** "Durch Prärien", **50** "Quer durch Cascadia".
- Whenever you pass a challenge, make **two crosses**: one at the challenge passed and one on the next free field of your route.

### Scenario goal legend
**Rulebook:** GS S. 12 (Legende – Szenarien)

| Icon | Goal |
|---|---|
| green circle with number # | Score at least # points (the # always stands for the number in the green circle) |
| X + species + "max" arrow | Reach the **highest possible score on the scoring card** with that species at least X times |
| X + habitat tiles + # | Score at least # points each with X habitats |
| species icons + # | Score at least # points with **each** of these species |
| habitat icons + # | Score at least # points with **each** of these habitats |
| **T** or **G** hexagon + # | Score at least # points in the whole category (T)iere (animals) or (G)ebiete (habitats) |
| species icons + X | Have at least X animals of **each** species shown |
| two species with red cross | These species must **not** be placed next to each other |
| two habitats with red cross | These habitats must **not** be placed next to each other |
| species on habitat with red cross | This species must **not** be placed on this habitat |
| two species with chain link | The first species must be **adjacent** to the second |
| X + species + # | Score at least # points each with X species |

## Landmarks challenge mode
**Rulebook:** LM S. 9

- **40 new challenges** in two areas: **Scenarios (20)** and **Normal game with landmarks (20)**. Same two-cross route system, up to 5 players. Route milestones: **10** "Wanderung", **20** "Reise", **30** "Erkundung", **40** "Entdeckung".
- Scenarios: each specifies scoring cards and **1–3 goals**, all required. The text says landmark scoring cards are added "from scenario 10" on, but the table (LM S. 10) lists landmark cards only from **scenario 11** (inconsistency within the rulebook). Any order; increasing difficulty. Solo: play in order.
- **Scenarios 11–20:** the same landmark card may be chosen by several players, even if already chosen – so several players can score the same card.
